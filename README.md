# Nassau Candy Product Line Profitability & Margin Performance Analysis

## Project Overview

This project analyzes product profitability, gross margin performance, division efficiency, and profit concentration for Nassau Candy Distributor.

The objective is to identify:

- High-profit products
- High-margin products
- Margin-risk products
- Best-performing divisions
- Cost inefficiencies
- Profit concentration risks

## Tools Used

- Python
- Pandas
- Plotly
- Streamlit
- Google Colab

## Dashboard Features

- Product Profitability Analysis
- Division Performance Dashboard
- Cost vs Sales Diagnostics
- Pareto Analysis
- Interactive Filters

## Files Included

- analysis.ipynb
- app.py
- clean_nassau.csv
- requirements.txt

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
